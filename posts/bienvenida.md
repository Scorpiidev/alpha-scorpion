# Bienvenida al blog
2026-07-19

Este es el primer post del blog. Puedes borrarlo o editarlo cuando quieras.

Para escribir una entrada nueva:

1. Crea un archivo `.md` dentro de la carpeta `posts/`.
2. La primera línea debe ser el título con `# Título`.
3. La segunda línea (no vacía) debe ser la fecha en formato `AAAA-MM-DD`.
4. Todo lo que escribas después es el cuerpo del post, en Markdown normal — puedes usar **negrita**, *cursiva*, listas, imágenes, enlaces, etc.
5. Añade el nombre del archivo a `posts/index.json`, arriba del todo si quieres que aparezca primero.

Sin backend, sin base de datos, sin coste. Solo Markdown.
